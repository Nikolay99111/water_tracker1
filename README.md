# Water Tracker

This simple script reminds you to drink water.

## Features

- Schedules a morning reminder "Доброе утро! Ты выпил воды?" at the specified time.
- After you record a drink, it reminds you every 2 hours.
- Stops sending reminders once the daily goal is reached.

## Usage

Run the script and input the amount of water (in ml) each time you drink.

```
python water_tracker.py
```

Press `exit` to stop the program manually.
