# water_tracker1

Приложение позволяет отслеживать количество выпитой воды и вести простую статистику.

## Настройки
- время напоминаний
- дневная норма
- число циклов

## Статистика
- график за выбранный период
- сколько выпито и сколько осталось

### Использование
```
# обновить настройки
python3 water_tracker.py settings --reminder-time 09:00 --daily-goal 2000 --cycles 8

# записать приём воды
python3 water_tracker.py log --amount 250

# посмотреть статистику за неделю с графиком
python3 water_tracker.py stats --days 7 --graph
```
