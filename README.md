# Water Tracker

A Flutter application to track daily water intake with notifications and statistics. Inspired by *The Last of Us* minimalistic style.

## Features
- Daily water counter with motivational messages.
- Local notifications reminding you to drink water.
- Statistics screen displaying the last 7 days with color-coded progress.
- Russian date formatting and month declension.

## Getting Started
Ensure you have Flutter installed. Add the required dependencies by running:

```bash
flutter pub get
```

Then run the app on a device or emulator:

```bash
flutter run
```
